## Changes

Implementation (one commit per fix, explicit paths):

- `93ae1bf` — `app/domain/src/storage.cpp`: new `createNew()` helper creates the temporary exclusively
  (`CreateFileW`/`CREATE_NEW` on Windows, `open`/`O_EXCL` elsewhere) and reports created / name-taken /
  cannot-create. `writeFileSafely` skips taken names (a retained D4 recovery copy, or another save in flight)
  and only proceeds with a file it created itself, so it never truncates a pre-existing file, and `discard()`
  only ever removes this call's own temporary — on the rejected path and on the successful path (the replacement
  consumes the temporary it is given). A cannot-create folder still throws the same
  "Cannot write in ..." `SaveError` as before. `tests/domain_tests.cpp`: +2 regression tests following the D4
  block's helpers (`cleanSong`/`temporaries`); each seeds 64 `.saving-N` recovery copies with distinct bytes (the
  suite's counter is already advanced, and is zero again in a fresh process, so the range covers any position).
- `5a5fe49` — `app/control/src/bridge.cpp`: `readAddon` checks `name`, `open`, `version`, `minCore` by type with
  a precise reason naming the file (the in-file `readAicoreStatus` precedent, `:180-182`); a wrong-typed field is
  an unusable add-on (`nullopt` + why), never a throw. `findAddon` continues per folder (try/catch around each
  `readAddon`), so one unusable folder cannot hide the next ones. Syntax errors were already safe
  (`readJsonFile:139-148`, non-throwing parse). `tests/calls_tests.cpp`: +2 regression tests (four malformed
  manifests incl. the probe's two, plus a well-formed manifest guard; malformed-first + valid-second
  `findAddon`).
- `8bce608` — `ci/gate.ps1` only (cherry-picked CI fix): the temporary launcher bat is named with a fresh GUID
  per invocation instead of the fixed `%TEMP%\core-gate.bat`, so concurrent gates from different streams no
  longer share a file that one can overwrite while the other's `cmd` is reading it. No product or test code.

Documentation (this commit): this report, one index row in `docs/relatorios/README.md`, and the verbatim sweep
archive in `docs/relatorios/evidencia/2026-11-18-sweep/`. `ESTADO.md` was not edited (D72/D80); proposed lines
below. No other file touched; `MainComponent.cpp` not edited; 05/03/06 not touched.
