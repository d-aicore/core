## Changes

Implementation (9 files, +200/−19 vs `f6b86dc`; no `engine/src` or DSP file touched, no native instrument/oscillator/filter added):

- `app/desktop/src/MenuIds.h` — additive offer model `addTrackFixedItems()` / `replaceFixedItems()` (BUG-SWEEP-09). The fixed
  (non-plugin) entries the menus offer: only an audio track and import; Replace offers plugins only. The built-in id bands
  (`kBuiltinAddFirst`, `kBuiltinReplaceFirst`), `kPluginBandFirst` and the decode routing are **unchanged** (menu32 preserved).
- `app/desktop/src/MainComponent.cpp` — showAddTrackMenu and showTrackMenu build their fixed entries from the offer model
  (the "Core's own instruments" section, the Sampler track entry and the Replace built-ins are no longer offered); the plugin
  path (`addPluginTrack`), audio track (`addAudioTrack`) and import are kept. The dispatch cases and decode calls are unchanged
  (the built-in ids are simply never emitted). Randomize sound enabled only when `styled && doc::soundAxisAvailable(...)`
  (BUG-SWEEP-11). Stale comments updated (the menu region, the `capturePluginsBefore` note). `giveSilentTracksPlugins` and the
  `kPluginSilent` menu are untouched.
- `app/domain/src/samples.cpp` / `.hpp` — `setTrackSample` refuses a plugin track (`DocumentError`, mirroring the audio/bus
  guard); `applySuggestedSamples` skips plugin role tracks so the bulk flow keeps their plugins and never throws (BUG-SWEEP-10).
  None/built-in tracks still take a sample (legacy preserved). Header contract updated.
- `app/domain/src/randomize.cpp` / `.hpp` — `soundAxisAvailable(doc)` mirrors the K loop's target condition; a sole sound axis
  with no built-in target returns `{}` (graceful no-op) instead of throwing (BUG-SWEEP-11). The K contract is otherwise unchanged.
- `tests/domain_tests.cpp` — 09 characterization (8 catalogue roles → `kind none`, 41 checks); 10 two tests (plugin survives a
  sample assignment; the bulk flow keeps a plugin role track, 9 checks); 11 one test (plugin-only styled song: no throw, axis
  unavailable, legacy built-in still has it, 4 checks). `samples.hpp` include added; the `droppedPluginKeys` comment corrected
  (setTrackSample no longer drops a plugin). No existing check removed or weakened.
- `tests/bug_tests.cpp` — 09 menu offer regression (21 checks) via the extracted `MenuIds.h` model; `MenuIds.h` include added.
- `tests/CMakeLists.txt` — `bug_tests` include dir adds `app/desktop/src` (for `MenuIds.h`).
