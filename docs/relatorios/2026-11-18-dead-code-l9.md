## NULL TEST (mandatory) — bit-exact before/after

Method: a harness (`evidence/tools/null-harness.cpp`) links `core_engine_lib` + `core_plugin_host` with the exact
`core-engine` compile/link flags (extracted from `build.ninja`) and calls `renderProject(p, 48000, block, false, 0.2,
nullptr, &assets, host, 0)` — serial export path — dumping raw float32 L+R. Compiled twice: against the pristine
`f6b86dc` libraries (before) and against `df33166` (after). Fixtures (`tools/make-fixtures.cjs`, deterministic):

1. **audio** — generated stereo WAV (220+1237 Hz L / 55+331 Hz R, 1.5 s, fades), 2 clips (offset/gain), bus1/bus2, send, master −3 dB, 145 bpm.
2. **legacy** — builtin kick/wave/hats/sampler tracks with notes, params, modulator, send; builtin effects eq/utility(bypass)/compressor(sidechain kick)/limiter v2 with params → all load unsupported, silent.
3. **plugins** — CoreTestSynth VST3 (4 notes, 2-bar pattern) + CoreTestGain VST3 inserts on track and master + audio track, 120 bpm. Descriptors from `core-engine scan` of the built test plugins.
4. **mixed** — synth + audio + buses/sends + plugin gain + legacy builtin effects (eq/utility/compressor-sidechain/limiter) + a builtin kick track, 145 bpm.
